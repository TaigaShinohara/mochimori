# もち守り デザイン整備記録（対象 v0.3.0 → 整備版 v0.3.1）

実施: 2026-11-19。本人の指示「デザイン整備スキルで整備して」を受け、meaningful_app_design スキルの手順（棚卸し → 意味の確認 → 3問テスト → 統一感チェック → 配置・配分から直す → カタログとトークンへ固定）で実施した。範囲は見た目・統一感のみ。機能・判定ロジック（BatteryJudge）・権限・署名は変更していない。

**判定の前提**: 実画面（レンダリング結果）はこの環境では見られない。統一感の判定はコード照合に基づく**仮判定**であり、実画面でしか判定できない項目は §6 に未確認として残す。AI の見立てで合格にはしない。

## 1. 棚卸し：画面ごとの意味（主役／狙う気持ち／手段）

設計 v0.3 と ART_DIRECTION に既にある定義を使い、実装と照合した。

| 画面 | 一番見せたいもの（主役） | どう思ってほしいか | 主な手段 | 実装との一致 |
|---|---|---|---|---|
| アプリ全体 | 何もしなくても電池が持つこと | 見守られてる。でも、うるさくない | 顔1つ＋最小の文字、先回りの自動調整 | 一致 |
| ホーム | 中央のバッテリーの顔（状態そのもの） | 一目で「大丈夫／まずい」が分かる安心・納得 | 顔の形と色、状態ラベル1語＋理由1行、必要な時だけ1ボタン | 一致（目安の文字サイズのみトークン違反 → §4-2） |
| 気づき | 今の無駄（最大3件） | 責められず「直せる」と思える | 件数見出し＋量のバー＋理由1行＋直すボタン | ほぼ一致（良好項目のバーの色、0件時の見せ方にズレ → §4-4, §4-5） |
| ルール | 自動プロファイルの階段（通常／節電／緊急） | 「任せて大丈夫」と分かる | 状態コンテナ色の階段カード3枚＋設定は最小限 | 一致（カード余白のリズムのみズレ → §4-1） |
| オンボーディング① | 「何もしなくても持つ」という約束 | 期待と安心 | アプリ名ヒーロー＋自動でできること | 一致（小見出しの階層 → §4-3） |
| オンボーディング② | 正直な線引き（1タップ／できないこと） | 誠実さへの信頼 | できる範囲を分けて正直に書く | ズレあり（見出しの色の使い方 → §4-3） |
| オンボーディング③ | 許可のお願いと「あとで」の逃げ道 | 強制されていない感じ | Filled=許可する／Text=あとで の階層 | 一致（注記の文字サイズ → §4-2） |
| ホーム詳細（折りたたみ） | 実測値（補助情報） | 知りたい時だけ静かに確認できる | 既定は畳み、開いたら BodySmall 1行 | 一致 |

## 2. 3問テストの仕分け（全要素）

問い: ①主役を見せるためか ②狙った気持ちになるか ③消しても伝わるか。

| 要素 | 判定 | 理由 |
|---|---|---|
| ホームの顔・状態ラベル・理由1行・目安・状態別アクション | 残す | 主役とその補助。3問すべてに答えられる |
| ホームの「詳細を見る」折りたたみ | 残す（畳んだまま） | 実測値は補助。既定で畳む現行が正しい |
| 気づきの量バー | 残す（色は項目の意味に合わせる） | 量の目安として有効。ただし良好項目で警告色は②に反する → §4-4 |
| 気づきのサンプルカード | 残す | R4（審査）で「件数に入らない」と明示した正直さの要素。見出しで分離済み |
| ルールの階段カード3枚 | 残す | 主役そのもの。状態コンテナ色＋on* 色の対応も正しい |
| ルールのスイッチ4項目相当（3スイッチ＋固定値1行） | 残す（固定値行の格下げ） | 設定を増やさない原則に一致。固定値行だけ行の見た目が設定行と紛れる → §4-6 |
| オンボーディング②の見出し3色（tertiary／warning／error） | 弱める | 1画面に役割色3色の見出しは「静か」に反する。特に error は「本当の緊急だけ」という方針と衝突 → §4-3 |
| オンボーディング①②の小見出し（TitleLarge） | 弱める | ページタイトルと同格で階層が平らになる → TitleMedium へ降格（§4-3） |
| ツールバーのアプリ名＋オンボーディング①のヒーロー「もち守り」 | 残す（許容する揺れとして記録） | 重複はあるが、ヒーローは初回の主役であり、ツールバーは全画面共通の殻。消すと①の主役が消える |
| 顔の中の稲妻マーク（常時表示） | 残す（観察事項） | 充電中は右上バッジで別途区別されており、実害は未確認。核の描画は本人の承認済みの形であり、整備の範囲では触らない |
| 炎アニメーション／結晶 | 残す | 状態の意味そのもの。動きを減らす設定で静止化も実装済み |

削った要素: なし（v0.2.0 の審査で既に削り切っており、今回新たに「意味を説明できない要素」は見つからなかった。弱めた要素は上記のとおり）。

## 4. 変更内容（v0.3.1）

すべて MainActivity.kt の見た目のみ。BatteryJudge・ProfileManager・Notifier・BatteryCheckReceiver・BatterySnapshot・BatteryFaceView は無変更。

1. **余白リズムのトークン化と統一**
   - 間隔定数を新設: `PAGE_PAD_H=20`（全画面の左右）、`CARD_GAP=12`（カード間隔）、`CARD_PAD_H=16 / CARD_PAD_V=12`（カード内）、`ACTION_GAP=24`（主アクション上の間隔）。
   - オンボーディング左右 28dp → 20dp、上 32dp → 24dp。
   - ルール階段カード: 間隔 10dp → 12dp、内側縦余白 10dp → 12dp（気づきカードと同一に）。
   - ホームの主ボタン上の間隔 16dp → 24dp（オンボーディングの主ボタンと同一に）。
   - 気づきの区切り見出し（良い状態／サンプル）の上に 16dp の区切り間隔を追加（カードに貼り付いて見える状態を解消）。
2. **文字トークンの遵守**: ART_DIRECTION／UI_CATALOG の「目安・注記 = BodySmall」に反していた2箇所を是正。ホームの「目安 約X時間」BodyMedium → BodySmall。オンボーディング③の注記「許可しなくても、見るだけなら使えます」BodyMedium → BodySmall。
3. **オンボーディングの見出し階層と色の規律**: 小見出しを TitleLarge → TitleMedium に降格し、ページタイトル（TitleLarge）との階層を作った。②の見出し色は warning／error をやめ onSurface に統一（error ピンクは本当の緊急だけ、という方針への準拠）。①の「自動でできること」は肯定的な意味を持つため cool のまま維持。
4. **気づきのバーの色を意味に合わせる**: 良好項目の LinearProgressIndicator が警告色（オレンジ）だったのを、良好項目は cool ロールで描くよう変更（Insight に good フラグを追加）。無駄項目は従来どおり warning。
5. **気づき 0件時の見せ方**: 無駄が0件のとき「今は無駄なし。良い状態です」（TitleMedium・cool）を出すようにした。裸の「0件」画面にしない。
6. **ルールの固定値行の格下げ**: 「節電に入る残量: 30%（固定）」を BodyLarge/onSurface（設定行と同じ見た目）→ BodyMedium/onSurfaceVariant（説明文の見た目）に変更。操作できる行と紛れないようにした。

新規パーツ: なし（すべて既存パーツの流用・バリエーションと配置・余白・階層の調整で済ませた）。

## 5. アート方針照合（項目別）

| 方針の項目 | 照合 | 備考 |
|---|---|---|
| 静かな見守り／ひんやり／正直 | 合致 | ②の見出しの色を落としたことで「静か」に近づいた |
| 状態色は役割固定 | 合致 | 変更後も役割の対応は不変。むしろ良好項目のバーと②見出しで役割外の色使いが2件解消 |
| 緊急ピンクは本当の緊急だけ | 合致（是正済み） | ②の「できないこと」見出しの error 色を撤去。error の出現はホームの緊急状態とルール階段の緊急カードのみ |
| 色だけに頼らない | 合致 | 炎／結晶の形の区別は不変。バーの色変更も形（バー自体）は不変 |
| 主役は顔1つ・角丸は大きめ・影は最小 | 合致 | カード elevation 0、角丸トークン不変 |
| ボタンとタブはピル型、選択は塗り＋白文字 | 合致 | M3 標準（Filled Button／Navigation Bar インジケータ）に委譲済み |
| 1画面1メッセージ、数字は主役にしない | 合致 | 詳細は折りたたみのまま。目安は BodySmall へ是正 |
| 責める・急かす文言なし | 合致 | 追加した0件時の一文も肯定的な言い方にした |
| 動きは炎の揺れのみ | 合致 | 変更なし |
| Dynamic Color は土台のみ、状態色は固定 | 合致 | テーマ・色トークンは無変更。light/dark の色トークン名の一致も確認済み |

## 6. 未確認（実画面でしか判定できない範囲）

- ぼかし見テスト（目を細めて主役が1つ浮かぶか）— コードからは判定できない。
- 余白統一後の実際の呼吸・間隔の感じ（特にオンボーディングの左右 20dp 化と主ボタン上の 24dp）。
- ライト／ダーク両テーマでの実際の色味、Dynamic Color が効いた端末（Pixel の壁紙連動色）での見え方。
- 大きな文字サイズ設定での見出し階層の崩れ、TalkBack の読み上げ順。
- 気づき0件時の一文が実データ状態でどう見えるか。
- これらは実機待ち行列の扱いとし、本人が触った時に一言もらえれば判定を確定できる。変更前／変更後を同じ条件で比べる画面写真が得られれば、ぼかし見を含む全体判定を写真に対して行う。
