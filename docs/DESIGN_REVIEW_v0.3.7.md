## 1. 棚卸し：ガラス適用後の画面ごとの意味（再確認）

意味の定義は全画面で不変（前回記録 §1 のまま）。変わったのは手段の質感だけである。

| 画面 | 主役 | 狙う気持ち | ガラス適用後の手段 | 意味との一致 |
|---|---|---|---|---|
| ホーム | 縦型＋液体の顔 | 一目で分かる安心 | 土台の光の上に顔が浮き、文字は土台へ直置き（不透明） | 一致。顔の背後の光が状態色の淡色である点は、顔のオーラと二重にならないか §3 で確認 |
| 気づき | 今の無駄 最大3件 | 責められず「直せる」 | 読み物ガラスカード（角丸 20dp）＋バー＋直すボタン（ベタ） | 一致 |
| ルール | 自動プロファイルの階段 | 「任せて大丈夫」 | 階段は役割ティント面、設定行は面なし（従来どおり） | 一致 |
| オンボーディング | 約束／線引き／許可のお願い | 期待と誠実さ | 土台の上に文字とボタン。進み具合ドットに色を付与（§4-1） | 一致 |

## 2. 3問テスト（ガラスで増えた・変わった要素）

| 要素 | 判定 | 理由 |
|---|---|---|
| 土台のグラデーション＋光3つ | 残す | Simple Glass の質感の本体。本人の採用決定に基づく。光は淡色ティントで文字と競合せず、数は正本の上限（4つ）以内 |
| ガラス面のふちハイライト | 残す | ガラスと半透明ベタを分ける唯一の手がかり。無いと「ただ薄い面」になる |
| カード角丸 12dp→20dp | 残す | 顔の角丸（22dp）とほぼ揃い、画面の形の言語が近づいた（§3） |
| トップバー／ナビのガラス帯 | 残す | 土台と地続きになり、画面の上下の「枠」感が消えた。タイトルとラベルの文字は不透明のまま |
| 進み具合ドットの tertiary 色 | 残す（今回付与） | 「現在位置」は形（●／○）だけだった。色＋形の両方で示す parts.md の流儀に揃えた。§4-1 |
| 液体の飛沫（作業3） | 残す | 本人の指示「バシャバシャ」の表現そのもの。器の中だけ・揺らした時だけ・ひんやり時は控えめ、と意味の条件を付けた（§4-2） |

**削った要素: なし。弱めた要素: なし。畳んだ要素: なし。** ガラス適用は質感の置き換えであり、要素の増減は土台と縁だけ。その2つは上のとおり3問に答えられる。

## 4. 変更内容（v0.3.8）

### 4-1. デザイン整備での指摘と対処

1. **進み具合ドットの現在位置に色を付与**（MainActivity.progressDots）: 従来は ●／○ の形だけ＋読み上げ名。現在ドットを tertiary（構造の役割色）のベタ色にし、色＋形の両方で現在位置を示す（parts.md のドット行の流儀）。新規パーツは作らず、既存 TextView への Span 付与のみ。
2. それ以外の指摘は作業1のゲートで是正済み（余白スケール 3件、カード角丸）。**整備側からの追加の指摘・変更は上記1件のみ**で、残りは合致を確認した。

新規パーツ: 作業1の `GlassDrawable`／`AppBackgroundDrawable`（Simple Glass の共通パーツ化として UI_CATALOG に登録）。整備側での新規パーツはなし。

### 4-2. 作業3：液体の滑らかさ＋バシャバシャ＋触覚同期（BatteryFaceView）

**滑らかさ**
- 液面のサンプリングを 26点の折れ線 → **44点＋中点2次ベジェ補間**の滑らかな曲線に（波面もメニスカス線も同じ曲線）。
- 波の成分を 2つ → **3つ**（細かい第3波を追加し、カクつきのない液面に）。
- 物理積分をフレーム実時間ベースのまま **≤8ms のサブステップ積分**にし、フレーム間隔が揺れてもバネ（傾き）とエネルギーの計算が滑らかで安定するようにした。アニメーターは従来どおり vsync 連動。

**バシャバシャ**
- 励起の源: 加速度センサーの線形加速度（重力推定との差、閾値 2.2m/s² 超）＋液面バネ自身の速度。速いアタック（約14/s）でエネルギー（0〜1）が立ち上がり、遅い減衰（約1.4/s、約2秒）で収まる。
- 表現: ①波高がエネルギーで最大 +5dp 増える ②**反射波**（主波と逆位相のカウンター波、最大 3.2dp）が現れ、内壁で跳ね返って戻る感じを出す ③**飛沫** 9粒が液面から放物線で跳ねて落ちる（液面のクリップ内だけ＝器の外には出ない）。
- 状態差（従来の流儀を維持）: ひんやり時は強さ 0.45 倍（穏やかさ優先でバシャバシャは控えめ）、充電中 0.7 倍、燃えている時 1.0 倍。静かに持っている時はエネルギーが立たず、従来の穏やかな動きのまま。
- 動きを減らす設定（ANIMATOR_DURATION_SCALE=0）では従来どおり全て静止（センサー未登録・アニメーター停止・エネルギーは 0 のまま）。

**触覚同期**
- 既存仕様（状態別の周期パルス、スイッチ、停止条件＝detach／背面／OS触覚OFF／アニメーター無効）はそのまま維持し、停止条件の判定を `hapticsAllowed()` に一本化した。
- 追加: バシャバシャのエネルギーが山（状態スケール後 0.5）に達した瞬間に、追加パルスを1発打つ。振幅はエネルギー連動で **34〜76（/255）**、36ms（従来のループパルスの帯 20〜56 と同じ「ささやき」の範囲に収め、上限も大きく超えない）。約450ms の不応期で連続振動（機械的な連打）にならないようにした。振幅制御のない端末では 20ms の短いパルス。

## 5. アート方針照合（項目別）

| 方針の項目 | 照合 | 備考 |
|---|---|---|
| 静かな見守り／ひんやり／正直 | 合致 | ガラスは静かな質感の範囲。バシャバシャは「揺らした時だけ」で常時うるさくしない |
| 状態色は役割固定 | 合致 | 色トークン・割当は無変更。ガラス面は色を塗らず、土台の光とティント面で出す |
| 緊急ピンクは本当の緊急だけ | 合致 | error の出現箇所は従来どおり |
| 色だけに頼らない | 合致 | 炎／結晶／液体の形は不変。ドットは色＋形に強化 |
| 主役は顔1つ・影は最小 | 合致 | 影は従来どおりなし（面は透けと縁で分離） |
| 1画面1メッセージ、数字は主役にしない | 合致 | 要素の追加なし（土台と縁は質感） |
| 動きの性格 | 合致（仕様を追記） | 液体の滑らかさ・バシャバシャは本人の今回の指示。ひんやり時の静けさ優先は状態スケールで担保 |
