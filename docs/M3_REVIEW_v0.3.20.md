# M3 標準化監査・実装記録（v0.3.21、対象 v0.3.20）

本人の指示（2026-11-21）: 「Material Design スキルで全体を見直しておいて。また、Androidデフォルトでありそうな画面レイアウトにして。ノイズとなる情報とかは消すか整理して。無駄な装飾も消していって」。

物差しは Material Design 3 スキル（material_design_3_ui、references: anti-patterns / shape-and-elevation / spacing-and-layout / component-selection / accessibility / color-system の要点）。あわせて meaningful_app_design の3問テストと minimal_information_design の原則で、装飾と情報の要否を判定した。

## 1. 監査結果 — M3 標準から外れていた点

| # | 対象 | 標準からの逸脱 | M3 側の根拠 |
|---|---|---|---|
| F-1 | 土台（AppBackgroundDrawable） | 3点グラデーション＋光（blob）3つの装飾背景。画面の地が色と光で主張する | anti-patterns「グラデーションで Material らしく見せる」。地は surface ロールのベタが標準 |
| F-2 | 全ての面（GlassDrawable） | 半透明グラス＋スペキュラ縁＋紙色のベールという独自質感。カード・バー・チップ・プレートの全面に使用 | M3 の面はコンポーネント既定の container ロール（不透明なトーン差）で作る。独自の面材は標準コンポーネントの状態表現（ripple・elevation overlay 等）と競合する |
| F-3 | 顔プレート（v0.3.11 案A） | 顔の背後の飾りガラスの板。情報を持たず、塊に見せるためだけの装飾 | meaningful 3問テスト: 主役（顔）を見せる役に立たず、消しても伝わる → 削除 |
| F-4 | 顔の装飾層（BatteryFaceView / WidgetFaceRenderer） | オーラ（呼吸するグロー）、きらめき（sparkle）、火の粉（ember)、落影、反射の帯（gloss)、スペキュラのリム、cavity の奥行き陰影、稲妻のグローと縁ハイライト、結晶のハロー、キャップのハイライト線 | anti-patterns「Motion/装飾は意味のためだけに」。状態を伝えるのは炎／結晶／液体／稲妻の形そのもので、光と粒の装飾は意味を持たない → 削除。液体・波・粒子・気泡・傾き連動・炎・結晶・稲妻・キャップは顔の核として残す |
| F-5 | カード角丸 20dp | テーマの Large を 20dp と自称しカードに適用。M3 のシェイプスケールは Large=16dp、カードの角丸は Medium=12dp が標準 | shape-and-elevation「角丸を全要素で最大化しない」「同じ役割は同じ形」 |
| F-6 | ルールの階段 | 色付きカード×3（primary/warning/error の container を全面ベタ＋ガラス）。3枚が同格に色で主張する | anti-patterns「全セクションをカードに入れる」「全コンポーネントを同格に expressive にする」。設定系画面の標準形はリスト行＋区切り |
| F-7 | 見出しの色 | ページタイトル・グループ見出し・折りたたみ見出し・オンボーディング見出しが tertiary（紫）ベタ。オンボーディングには状態色 cool の見出しも | 見出しは onSurface が標準。色は状態と操作の意味がある所だけに使う。状態色の装飾流用は状態表示と紛らわしい |
| F-8 | 「数値を見る」トグル | ガラス面の自作ピルチップ（TextView＋RippleDrawable） | component-selection / anti-patterns「チップを汎用ボタンの代わりにしない」。低強調の開閉操作は Text Button が標準 |
| F-9 | チェックリスト頭のシェブロン | 文字グリフ「⌄」を TextView で描画 | 標準はベクターアイコン（expand_more）。グリフはフォント依存で形が安定しない |
| F-10 | 状態マーク | ✓/！/？/i の文字グリフを色付き円に描く自作マーク | 標準は Material アイコン（check_circle / error / help / info）。形＋色の両立という仕様自体は維持し、描き方だけ標準化 |
| F-11 | チェック行の高さ 36dp | M3 のタッチターゲット下限 48dp 未満。v0.3.19 で「全表示」の収まりのために詰めた名残 | accessibility「ターゲットは 48dp 以上」。v0.3.20 で開閉式になり、展開時は下部エリアの内部スクロールが受け皿になったため、48dp に戻しても既定状態の収まりは壊れない |
| F-12 | ツールバー／下部ナビの色 | 帯ガラスの背景＋選択色の手動指定（primary アクティブ等） | Navigation Bar / Top App Bar はコンポーネント既定の container 色と状態色に委ねるのが標準 |
| F-13 | ウィジェットのパネル | グラデーション＋スペキュラ縁のガラス | アプリ側と同じく、面はベタ＋角丸のみに |
| F-14 | オンボーディングの進みドット | 現在位置が tertiary ベタ | 色の意味を構造色に使わない。primary（操作・現在位置の標準色）に統一 |

## 2. ノイズ情報の棚卸し

文言面のノイズは過去の監査（情報最小化 v0.3.3、情報整理 v0.3.18）で除去済みで、今回新たに「読まなくても困らない文言」の削除対象は見つからなかった。残っている注記類はすべて正直さの担保（取れない値の「確認中」、推定の「目安／推定」表記、限界モードの効果先を示す注記、許可の要否）であり、情報ではなく正確さの担保として残す。今回のノイズは主に**視覚ノイズ**（F-1〜F-4 の装飾と、F-7 の色の付けすぎ）だった。

## 3. 実装（v0.3.21）

- **土台**: AppBackgroundDrawable を廃止し、全画面の地は `colorSurface` のベタ。ファイル削除。
- **面**: GlassDrawable を廃止（ファイル削除）。カードは MaterialCardView の filled card（container は surfaceContainer ロール、不透明）、角丸は Medium 12dp。ツールバーと下部ナビは背景・色指定を外しコンポーネント既定に委ねた。
- **顔プレート**: 削除（レイアウト追随コード layoutPlate / installPlateFit も撤去）。ホームの並び・ウェイト方式（v0.3.20）は不変。
- **顔の質感**: 装飾層を全て落とした（F-4）。本体の殻は container 色のベタ塗り、輪郭は状態色のベタ線、キャップは金属グラデーションのみ（ハイライト線なし）。液体のグラデーション（深さの読み）、波・粒子・気泡、炎、結晶、稲妻、傾き連動、触覚は不変。WidgetFaceRenderer も同じ簡素化を適用。
- **ルールの階段**: 1枚のカードに3行（状態色のドット＋タイトル＋詳細）＋区切り線（outlineVariant）の形に再編。カード自体は他のカードと同じ surfaceContainer。
- **見出し**: tertiary／cool のベタ色を全て onSurface に（ページタイトル、グループ見出し、折りたたみ見出し、オンボーディング見出し）。状態ラベルの状態色は意味があるので不変。
- **「数値を見る」**: ガラスチップを廃止し、M3 Text Button（materialButtonTextButtonStyle）に。ラベル色はテーマ既定（primary）。
- **副ボタン（textButton）**: 手動の透明化＋secondary 指定をやめ、Text Button スタイル既定に委ねた（「あとで」「許可する」も同じ）。
- **シェブロン／状態マーク**: ベクターアイコン化（ic_expand_more / ic_check_circle / ic_error / ic_help / ic_info を res/drawable に追加）。マークの色づけ（OK=cool、NG=warning、確認中・案内=onSurfaceVariant）と形＋色の両立は不変。
- **チェック行**: 48dp に戻した（CHECK_ROW_H=48）。チェックリストカードの縦余白も通常カードと同じ 12dp に統一（CHECK_CARD_PAD_V を廃止）。
- **シェイプトークン**: ShapeAppearance.Mochi.Large を 20dp → 16dp（M3 スケール準拠）。カードは Medium 12dp を明示。
- **進みドット**: 現在位置を primary に。
- **ウィジェット**: パネルは surface 色ベタ＋角丸 20dp のみに（drawable-night の重複ファイルは削除し、トークン参照で一本化）。

## 4. 残したもの・意図的な標準からの乖離

- **Dynamic Color は使わない**（v0.3.9 の決定を維持）。M3 標準は Dynamic Color だが、本人の実機で壁紙色が土台に流れ込み見づらくなった知見が正本。テーマは固定パレットのまま M3 のロール体系に載せる。この乖離は意図的で、ART_DIRECTION に明記する。
- **状態色の固定ロール**: 顔と状態ラベルは colorMochiStateCool / colorMochiWarning の固定ロールを使う（M3 に warning ロールが無いためのカスタムロール含む）。意味の固定が正直さの担保。
- **ドーナツ＋％**: 本人指定の可視化。M3 に相当コンポーネントは無いが、情報（割合）を伝える中身であり装飾ではないので残す。
- **顔の液体アニメーション・粒子・傾き連動・触覚**: 状態の意味そのもの（静けさ／燃え／溜まる）であり、過去に本人が個別に指示・承認した核。残す。
- **チェックリストのカード**: 「1つのまとまり」としてのカードは M3 でも正当（contained unit）。行ごとのカード化はしていない。
- **ホームのウェイト方式レイアウトと開閉仕様**（v0.3.20）: 不変。

## 5. セルフオーディット（M3 スキル）

| カテゴリ | スコア | 根拠 |
|---|---|---|
| Task clarity | 2 | 画面の主目的は従来どおり（ホーム=状態、ルール=設定） |
| Information hierarchy | 2 | 見出しの色を落とし、地と面の主張を消したことで顔と状態が主役に戻った |
| Component semantics | 2 | チップ→Text Button、グリフ→標準アイコン、階段→リスト行。操作の意味と部品が一致 |
| Token discipline | 2 | 面は surface / surfaceContainer ロール、形は M3 スケール（12/16）に統一 |
| Adaptive behavior | 1 | 従来どおり compact 前提（本アプリの対象は本人のスマホ。広い画面の最適化は対象外として据え置き） |
| States & feedback | 2 | 既存の状態・フィードバックは不変 |
| Accessibility | 2 | 行ターゲット 48dp に復帰。状態は形＋色の両立を維持。コントラストは不透明面化でむしろ安定 |
| Expressive restraint | 2 | 表現は顔（状態の形）1か所に集約し、それ以外は静かにした |
