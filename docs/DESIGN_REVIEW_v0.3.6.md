### v0.3.6 の顔まわりのバランス（重点確認）

- 顔枠は高さ 320dp（v0.3.6 で 236dp から拡大）。枠の中で BatteryFaceView が本体（幅：高さ ≈ 1：1.55、上部キャップ）を組み立てる: 上部 58dp は炎・結晶の余白、下部 20dp は落影の余白、本体は残りの高さいっぱい（上限 272dp）に置かれる。対象端末の幅では本体は枠幅の約42%の幅で中央に立ち、左右はオーラと結晶・炎の広がりに使われる — 主役の置き方として成立している（コード上の寸法照合）。
- 顔枠の下端（落影）から状態ラベルまでの実効間隔は約7dp で、顔とラベルが1つの塊として読める。理由→主アクションは ACTION_GAP=24、副アクション（数値を見る）は 8dp と、v0.3.4 で整えた部品ルールのまま。状態によって間隔の出方が違う（ボタンがある状態／ない状態）が、これは部品ルール（主アクション=24、テキストボタン=8、ラベル積み=3+3）の適用結果であり、画面の発明ではない。
- ラベル共通の上下 3dp パディング（label() ヘルパー）は全画面共通の本文積みリズムとして機能している。トークン表には載っていないが、全画面で均一であり今回は触らない（観察事項として記録）。

## 2. 3問テストの仕分け（v0.3.1 以降に増えた・変わった要素を中心に）

問い: ①主役を見せるためか ②狙った気持ちになるか ③消しても伝わるか。

| 要素 | 判定 | 理由 |
|---|---|---|
| 液体＋液面の波・気泡（v0.3.6） | 残す | 残量そのものの表現であり、主役の手段そのもの。気泡は状態の意味（充電=溜まっている、燃焼=少し活発、ひんやり=ほぼ静か）と対応している |
| 傾き連動の揺れ（v0.3.6） | 残す | 本人の指示。液面が物理らしく振る舞うことで「液体である」ことが説明なしに伝わる。センサーは表示中だけ登録され、動きを減らす設定では止まる |
| 炎の帯（v0.3.5） | 残す | 状態の意味そのもの。本人の実機評価「いい感じ」を受けた形 |
| 触覚フィードバック＋ルールのスイッチ（v0.3.5） | 残す | 本人の要望。スイッチは既存の switchRow パーツの流用で増えており、画面の言語は増えていない |
| オーラの呼吸（ひんやり時） | 残す | 「静かな見守り」の演出。結晶そのものは動かさず、光だけがゆっくり呼吸する範囲に留まる |
| きらめき（4点星の瞬き） | 残す（観察事項のまま） | INFO_MIN_REVIEW R-10③ で観察事項として記録済み。蒸し返さない |
| ホームの重み付きスペーサー（v0.3.4） | 残す＋オンボーディングへ展開 | 単一クラスタ画面の配置ルールとして正本化した（§4-1） |
| 進み具合ドット（v0.3.3） | 残す | 図形で「あと何画面か」を伝える。読み上げ名も持つ |
| 顔枠の高さ 320dp（v0.3.6） | 残す（トークン化） | 主役の大きさの指定そのもの。無名の数値だったため定数化した（§4-2） |
| オンボーディングの上寄せ配置（従来） | 直す | 要素ではなく配置の問題。§4-1 で分布の言語をホームに揃える |

観察事項（今回は触らない）:
- スイッチ行の縦パディング 10dp と気づきカード内のバー前後 6dp はトークン表外の値だが、それぞれの場面で均一に使われている。

## 4. 変更内容（v0.3.7）

新規パーツ: なし。色・サイズの新規追加: なし（FACE_H は既存値の定数化）。

1. **オンボーディングの縦分布をホームに揃える**（MainActivity.showOnboarding）
   - 変更前: ScrollView が内容の高さでラップし、塊は上寄せ。下半分は空白。
   - 変更後: ScrollView に `isFillViewport = true`、内容カラムを MATCH_PARENT 高にし、塊の上下に重み付きスペーサー（weight 1）を追加 — ホームと同一のパターン。内容がビューポートを超える場合はスペーサーが潰れて通常スクロールになる（ホームと同じ挙動）。
   - 狙い: 単一クラスタ画面の配置ルールを1つにし、最初に見る画面（オンボーディング）とホームが同じアプリに見えるようにする。
2. **顔枠の高さをトークン化**（MainActivity）
   - `dp(320)` のリテラル → companion の定数 `FACE_H = 320`。値と見た目は不変。UI_CATALOG のトークン節に登録し、内部寸法は BatteryFaceView が持つことを明記。
3. **ART_DIRECTION「動きの性格」の追随**（文書のみ）
   - 要約節を v0.3.6 の実装に合わせて書き直した（液体の波と傾き連動、充電の気泡と脈動、呼吸するオーラ、触覚、動きを減らす設定での全面静止）。実装の変更ではなく、本人が指示・承認した内容への方針文書の追随であり、詳細仕様の節（顔の描画仕様）とは元々一致していた。
4. **UI_CATALOG の反映**
   - 冒頭の変更履歴に v0.3.7 を追加。トークン節に FACE_H を登録。「ホームの縦配置」の項目を「単一クラスタ画面の縦配置」に改め、オンボーディングへの展開と、一覧型画面は対象外であることを明記。

変更ファイル: MainActivity.kt（配置と定数のみ）、app/build.gradle.kts（バージョンのみ）、docs/ART_DIRECTION.md、docs/UI_CATALOG.md。BatteryFaceView・BatteryJudge・他クラスは無変更。

## 6. 未確認（実画面でしか判定できない範囲）

- ぼかし見テスト（目を細めて主役が1つ浮かぶか）— コードからは判定できない。
- オンボーディングの分布変更後の実際の呼吸（塊が中央に分布して見えるか、小さい画面でスクロールに崩れる境界）。

- ライト／ダーク両テーマでの実際の色味、Dynamic Color が効いた端末での見え方。
- 大きな文字サイズ設定での崩れ、TalkBack の読み上げ順。
- 触覚フィードバックの実際の感じ方（強さ・タイミング）。
- これらは実機待ち行列の扱いとし、本人が触った時に一言もらえれば判定を確定できる。変更前／変更後を同じ条件で比べる画面写真が得られれば、ぼかし見を含む全体判定を写真に対して行う。
